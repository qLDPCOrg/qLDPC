# Citation

If you use this experiment, or the codes that it finds, please cite the paper:

```bibtex
@misc{perlin2026quantum,
  title = {Quantum codes from classical annealing},
  author = {Perlin, Michael A. and Steinberg, Matthew and Criger, Ben},
  year = {2026},
  eprint = {2607.19574},
  archivePrefix = {arXiv},
  primaryClass = {quant-ph},
  doi = {10.48550/arXiv.2607.19574},
  url = {https://arxiv.org/abs/2607.19574},
}
```

Alternatively:

```text
Michael A. Perlin, Matthew Steinberg, and Ben Criger. Quantum codes from classical annealing. arXiv:2607.19574, 2026.
```

The experiment is built on qLDPC; to cite qLDPC as well, see the [attribution section](../../README.md#-attribution) of its README.
